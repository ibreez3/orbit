# Orbit Custom Themes

Place your `.orbit-theme` files in this directory.

## Format

```ini
name = My Theme Name

[palette]
background = #1e1e2e
foreground = #cdd6f4
ansi-0 = #45475a
ansi-1 = #f38ba8
ansi-2 = #a6e3a1
ansi-3 = #f9e2af
ansi-4 = #89b4fa
ansi-5 = #f5c2e7
ansi-6 = #94e2d5
ansi-7 = #bac2de
ansi-8 = #585b70
ansi-9 = #f38ba8
ansi-10 = #a6e3a1
ansi-11 = #f9e2af
ansi-12 = #89b4fa
ansi-13 = #f5c2e7
ansi-14 = #94e2d5
ansi-15 = #a6adc8

[window]
background = #11111b

[cursor]
color = #cdd6f4
```

## Color Reference

- `ansi-0` through `ansi-7`: Standard colors (black, red, green, yellow, blue, magenta, cyan, white)
- `ansi-8` through `ansi-15`: Bright/bold variants
- Colors use hex format: `#rrggbb`

Restart Orbit to pick up new themes.
