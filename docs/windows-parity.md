## MySQL 实例和表浏览（2026-11-19）

- 数据库名称可选。留空时枚举有权限访问的库，在工作台顶部选择；指定库时固定显示。运行时选择不写回连接配置。
- 结构、SQL、备份、恢复和映射导入显式携带目标数据库；Rust 拒绝固定库连接切库。
- 点击表进入“表数据”，执行只读 `SELECT * ... LIMIT 200`；“SQL 查询”保留手写草稿。MySQL 表名使用反引号并转义。
- 切换数据库刷新结构并隔离旧结果。备份包含来源数据库且文件名唯一，避免连续备份不同库时覆盖。
- 本地验证：32 项 Rust 数据库测试、9 项 Swift SQL 策略测试、21 项完整 WebView 回归通过；macOS Release 构建及签名检查通过。
- 隔离实例验证：两库枚举/切换、查询实际库、配置不变、固定库限制、250 行测试表只返回 200 行、所选库备份通过。
- Windows 增量 Release 和 NSIS 构建通过。WebView2 真机验证同样通过，已启动关闭调试端口的开发构建；本次测试连接、备份和容器已清理。安装包尚未进行安装/升级验收，未发布。

IPC mock 不替代真机验收。此前 Windows 直连用户提供的 MySQL 曾验证成功；后续网络切换时 Windows 缺少目标网段 VPN 路由，不能把历史成功当作当前连通证据。
