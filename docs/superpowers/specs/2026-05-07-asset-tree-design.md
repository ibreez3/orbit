# 资产树 + 页面重构 设计

## 概述

重新设计首页布局，引入左侧常驻资产树导航面板，重构欢迎页，保留右侧 AI 面板。

## 布局

```
┌──────────────┬────────────────────────────┬──────────┐
│  资产树       │  TabBar                    │  AI 面板  │
│  (左侧,常驻)  │  ┌──────────────────────┐  │  (右侧)   │
│              │  │   内容区              │  │  (不变)   │
│ 📁 生产环境   │  │  无tab → 欢迎页       │  │          │
│  ├─ web-01   │  │  有tab → 终端/SFTP    │  │          │
│  ├─ db-01    │  │                      │  │          │
│ 📁 测试环境   │  └──────────────────────┘  │          │
│ 📁 凭据组     │  StatusBar               │          │
│ 📁 命令片段   │                           │          │
│ [+] 添加服务器 │                           │          │
└──────────────┴────────────────────────────┴──────────┘
```

## 资产树（左侧面板）

### 树形结构
- **服务器分组节点**（按 `group_name` 分组，"默认" 组名显示为 "服务器"）
  - 展开/折叠箭头
  - 分组名 + 服务器计数 badge
  - 子节点：服务器名称 + host 缩写 + 在线状态指示点
- **凭据组**（独立分组，列出所有 CredentialGroup）
- **命令片段**（独立分组，列出所有 CommandSnippet，按 tags 子分组）
- **底部工具栏**：[+] 添加服务器、[🔍] 搜索

### 交互
- 单击服务器节点 → 在中间打开 SSH 终端 tab
- 右键菜单：终端 / SFTP / 监控 / 编辑 / 删除
- 双击凭据组 → 打开编辑
- 单击命令片段 → 如果当前有活跃终端则直接执行，否则复制到剪贴板
- 拖拽分组标题栏可调节面板宽度（160-350pt），持久化

### 视觉
- 紧凑列表风格，行高 28pt
- 选中项高亮
- 搜索框在顶部（过滤服务器名/host）

## 欢迎页（中间区域，无 tab 时显示）

### 内容
- 顶部：Orbit logo + "欢迎回来" 标题
- 快捷操作行（3-4 个胶囊按钮）：
  - `⌘N` 新终端（本地终端）
  - `⌘+` 添加服务器
  - `✨ AI 助手` 打开 AI 面板
  - `⌘K` 命令面板
- 最近连接区域：
  - 标题："最近连接"
  - 最多显示 6 个最近打开过 tab 的服务器
  - 每项显示：服务器名、host、最后连接时间
  - 点击直接打开 SSH 终端 tab

### 最近连接追踪
- 在 `AppState` 中维护 `recentServers: [String]`（最多 6 个 serverId，按最近打开顺序）
- 在 `addTab(server:)` 时更新
- 持久化到 UserDefaults
