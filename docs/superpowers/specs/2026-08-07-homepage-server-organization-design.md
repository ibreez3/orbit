# Orbit 首页与服务器组织重构设计

## 1. 目标

Orbit 启动后的首要任务是连接服务器并进入工作，不展示占据首屏的品牌欢迎内容。首页应让已保存服务器能够通过一次点击或一次回车连接，让未保存服务器能够从一个入口发起临时连接，并让低频功能保持可达但不抢占主视觉。

本次同时重构服务器的组织能力，使目录只承担用户自定义的层级组织，标签承担跨目录属性分类，避免把项目、环境、技术类型和网络角色混在同一分组维度中。

## 2. 范围

### 2.1 本次范围

- 首页顶部服务器快速连接与搜索入口。
- 单列最近连接列表、置顶与连接结果状态。
- 首页辅助入口与右侧 AI 入口层级调整。
- 服务器 1～3 级自定义目录。
- 服务器多标签。
- 现有服务器 `group_name` 到一级目录的数据迁移。
- 左侧服务器树的搜索、目录管理、拖拽移动和标签筛选。
- 临时 SSH 连接的紧凑认证流程。

### 2.2 不在本次范围

- 数据库、凭据组和命令片段的数据结构或分组方式。
- 运维总览模式、在线率统计或异常服务器仪表盘。
- 后台周期性服务器可达性探测。
- 目录级用户名、密码、密钥或其他连接属性继承。
- 多协议连接、云同步或团队共享目录。

## 3. 布局

默认窗口参考尺寸为 1280×800，最小兼容尺寸为 1024×640。

### 3.1 顶部全局栏

- 高度 40pt。
- macOS 窗口控制区保持系统行为。
- 页面标题弱化展示为“SSH 工作台”。
- 中间只保留一个服务器连接输入框。
- 输入框默认宽度约 500pt，随窗口宽度弹性收缩。
- 右侧保留新增菜单和设置入口。
- 小窗口下优先隐藏页面标题和辅助文字，保证输入框与窗口操作不碰撞。

顶部输入框只负责服务器，不展示命令或应用操作：

- 搜索服务器名称、主机地址、目录路径和标签。
- 解析 `[user@]host[:port]` 临时连接地址。
- `⌘K` 聚焦输入框。
- `Esc` 关闭结果或临时认证面板，并将焦点还给当前终端。

### 3.2 左侧资产栏

- 默认宽度 240pt。
- 支持在 180～360pt 之间拖拽。
- 支持折叠为 48pt 图标栏。
- 持久化最后一次宽度和折叠状态。
- 深层目录或长名称使用省略号，悬停显示完整路径。
- 顶部“搜索资产”只过滤左侧资产树，不发起连接。

服务器分类树使用新的目录与标签模型。数据库、凭据组和命令片段继续沿用当前结构。

### 3.3 主内容区

- 最大宽度 800pt，水平居中。
- 首页不再展示 logo、大标题和说明文案。
- 最近连接是主内容区第一个模块和唯一内容主体。
- 默认完整展示 8 条最近连接。
- 列表下方展示一组自然宽度、整体居中的紧凑按钮：本地终端、添加服务器、命令面板。
- 按钮组宽度控制在约 360～420pt，不拉伸为等宽卡片。
- AI 助手移入右侧工具栏，不在首页和核心操作同权。

### 3.4 右侧工具栏与底部状态栏

- 右侧工具栏宽度 48pt。
- AI 与文件、监控等扩展工具同层。
- 所有纯图标入口必须提供 tooltip 和辅助功能标签。
- 底部状态栏高度 24pt，左侧显示活动会话摘要，右侧显示核心快捷键。

## 4. 服务器目录与标签

### 4.1 目录规则

- 用户可以自由创建、命名、排序和移动目录。
- 目录最多 3 级。
- 每台服务器最多属于一个实体目录。
- 无目录服务器归入系统视图“未分类”。
- 禁止把目录移动到自身或后代节点下。
- 禁止移动后产生超过 3 级的树。
- 删除空目录可直接确认删除。
- 删除非空目录必须选择将服务器移动到其他目录或连同服务器删除。

### 4.2 标签规则

- 每台服务器可以包含 0～多个标签。
- 标签与目录正交，不改变服务器的目录归属。
- 标签用于环境、技术类型、网络角色等跨目录属性，例如 `生产`、`K8S`、`内网`、`跳板机`。
- 标签默认使用中性视觉样式，选中时使用主题强调色，不为不同标签随机分配强色。
- 第一阶段支持按单个标签过滤；组合过滤不进入本次范围。

### 4.3 系统视图

以下节点由查询结果派生，不是可移动、重命名或删除的实体目录：

- 全部服务器。
- 置顶。
- 最近连接。
- 未分类。

### 4.4 目录交互

- 单击目录展开或收起。
- 目录折叠按钮和整行具有足够点击热区。
- 服务器可拖拽到目录。
- 目录可拖拽调整父目录和顺序。
- 右键菜单包含新建子目录、重命名、删除。
- 当目录已位于第 3 级时，不显示“新建子目录”。

## 5. 搜索与命令边界

### 5.1 顶部服务器输入框

只返回：

- 已保存服务器。
- 与输入匹配的目录路径和标签信息。
- 合法临时连接地址的连接动作。
- 固定的“新建服务器”入口。

### 5.2 命令面板

- 通过首页居中按钮或 `⌘⇧P` 打开。
- 只处理应用操作和命令片段。
- 不返回服务器快速连接结果。

### 5.3 左侧资产搜索

- 只过滤左侧当前资产树。
- 服务器匹配字段包括名称、host、目录路径和标签。
- 搜索结果保留服务器所在路径提示。

## 6. 连接流程

### 6.1 已保存服务器

- 搜索结果回车、最近连接整行点击或服务器树双击均使用已保存认证信息建立 SSH 会话。
- 成功后更新最近连接顺序和最近成功结果。
- 失败后记录最近一次连接失败状态与可展示的错误摘要。

### 6.2 临时服务器

1. 用户输入 `[user@]host[:port]`，端口缺省为 22。
2. 输入合法但不是已保存服务器时，回车在输入框下展开紧凑认证面板。
3. 面板支持：用户名、密码或密钥认证、凭据组、可选跳板机。
4. 不默认使用 `root`，不自动复用其他服务器的密码。
5. 默认选择“仅本次连接”。
6. 用户主动启用“保存到资产”时，才要求服务器名称和可选目录，并在连接成功后保存。
7. 信息完整后再次回车或点击“连接”建立临时会话。

临时连接不得强制打开完整的添加服务器表单。

## 7. 最近连接

### 7.1 行内容

从左到右展示：

- 8pt 状态点。
- 服务器名称。
- 可选目录或标签。
- 等宽字体的 `IP:端口`。
- 相对连接时间。
- Hover 时出现的更多操作。

整行可点击连接。更多操作包含连接、编辑、置顶或取消置顶、移动目录和删除。

### 7.2 排序

- 置顶服务器固定在列表最前面。
- 多个置顶服务器按用户置顶顺序排列。
- 未置顶服务器按最近连接时间倒序排列。
- 首页展示前 8 条，“查看全部”切换到服务器完整列表或对应系统视图。

### 7.3 状态语义

状态不表示实时网络可达性：

- 绿色：当前存在活动 SSH 会话。
- 红色：最近一次连接尝试失败。
- 灰色：未连接、连接已结束或状态未知。

悬停必须显示“活动中”“上次连接失败”或“未检测”，不得显示未经后台探测支持的“在线/离线”。

## 8. 数据模型

建议新增：

```text
server_folders
  id
  name
  parent_id nullable
  sort_order
  created_at
  updated_at

server_tags
  id
  name
  normalized_name unique
  created_at
  updated_at

server_tag_links
  server_id
  tag_id
  primary key (server_id, tag_id)
```

`servers` 增加：

```text
folder_id nullable
is_pinned
pin_order nullable
last_connected_at nullable
last_connection_result nullable
```

标签名称保存用户输入的展示形式，`normalized_name` 使用去除首尾空白后的不区分大小写值，防止产生视觉重复标签。

活动会话状态继续来源于运行时会话数据，不持久化为“在线”。

第一阶段不在目录上保存认证或连接属性，凭据复用继续通过现有凭据组完成。

## 9. 迁移

- 每个非空旧 `group_name` 创建一个同名一级目录。
- 服务器关联到对应目录。
- 空 `group_name` 保持 `folder_id = NULL`，显示在“未分类”。
- 第一版迁移保留旧 `group_name` 列但不再作为界面数据源，避免不可逆地破坏旧数据；新目录操作只维护 `folder_id`。
- 不根据旧分组名称自动生成标签，避免错误推断用户语义。
- 重复目录名按标准化后的原始分组值合并，但不得修改服务器认证、跳板机或连接字段。
- 迁移必须可重复执行，不重复创建目录或标签关系。

## 10. 错误与空状态

- 无最近连接：显示“暂无连接记录”，并提供添加服务器和打开本地终端两个入口；顶部输入框仍是首要操作。
- 临时地址格式错误：在输入框下就地提示合法格式，不打开认证面板。
- 临时认证失败：保留用户已填内容，展示失败原因，不自动保存资产。
- 目录移动非法：保持原位置并说明是循环或层级超限。
- 删除目录失败：不改变树，展示后端错误。
- 旧数据迁移失败：事务回滚，应用不得进入部分迁移状态。

## 11. 可访问性与键盘

- 主要文字与背景对比满足 WCAG AA 的普通文本要求。
- 不以颜色作为状态的唯一表达，状态点提供 tooltip 和辅助功能文本。
- 目录展开、服务器连接和更多操作均可通过键盘访问。
- 行点击热区覆盖整行。
- 目录折叠按钮、更多操作和右侧工具按钮具有不小于 28×28pt 的交互热区。

## 12. 验收标准

- 首页不存在重复连接输入框。
- 已保存服务器可通过一次点击或一次回车进入会话。
- 未保存服务器无需先创建资产即可进入紧凑认证流程。
- 顶部服务器输入框、左侧资产搜索和命令面板职责无交叉。
- 默认窗口完整展示 8 条最近连接和居中辅助按钮组。
- 1024×640 下核心操作不被遮挡。
- 侧边栏在 180～360pt 间可调，折叠和宽度状态可恢复。
- 目录最多 3 级，拖拽不能产生循环或超限层级。
- 每台服务器支持一个目录和多个标签。
- 状态点不宣称未经探测的在线状态。
- 旧服务器迁移后数量、认证、跳板机和连接信息不变。
- 数据库、凭据组和命令片段行为不发生变化。
